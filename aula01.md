# Conteúdo - Aula
- Sistema de Informaçãao/Conhecimento
   - Conjunto de partes/aspectos
       - Aspectos funcionais: motivo da existência
       - Aspectos estruturas: o que se quer guardar
         
Exemplo: 
- Funcionalidades:
    - gerenciar times;
    - jogos;
    - estádios;
    - áebritos;
    - tabela de classificação -> gerenciar vitórias, empates, saldos de gols;

- Estruturas:
    - times;
    - jogos;
    - estádios;
        - time: nome; sigla;
        - estádios: nome;
        - jogos: times; estádio; hora; data; árbitro;
        - classificação: jogo
